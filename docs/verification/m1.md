## Issues encountered and practical limits

1. Java/Maven were not installed on PATH initially. Development-only JDK and Maven were downloaded under ignored `.tools`; a fresh clone still needs JDK 21. Wrapper and source are committed, toolchains are not.
2. Windows Application Control rejected unsigned OpenJFX Maven native `glass.dll` on the Temurin runtime. The standalone Gluon SDK inspected here was also unsigned. The official BellSoft Java **21.0.13.0.3+5 Full** distribution supplied valid signed native libraries and successfully ran tests/UI using bundled JavaFX **21.0.13.0.3**. Compile artifacts remain pinned to OpenJFX 21.0.13. This machine requires a policy-approved runtime; no security-policy bypass is included.
3. Direct Maven clean repeatedly failed to delete a generated read-only directory in this OneDrive-backed checkout. Native PowerShell cleanup of verified generated output succeeded, followed by a successful clean build. `scripts/dev.ps1 -Task build` includes that scoped cleanup; normal Maven verify works. A nonsynced checkout is preferable.
4. The initial UI-test button lookup ran before the new ScrollPane skin had been created. Corrected the test to apply CSS/layout before lookup and use a stable control ID; final real-window suite passed.
5. Foundation ledger queries load/filter/sort session facts in memory for exact timestamp correctness. M3 must add lifecycle snapshots, per-day checkpoints and paged/indexed history. Classroom/workspace CRUD, timers, Windows enforcement, goals/statistics workflows, rewards, transfer/presets and packaging remain pending in their named milestones.
6. Minimum-size window construction was tested; exhaustive 100/125/150% DPI and accessibility acceptance remains M8 work. No self-contained installer/app image is delivered in M1.
